# 안전점수 산정 방식

## 결론: AHP 기반 가중합 방식이 가장 현실적이다

현재 프로젝트에서 가장 현실적인 안전점수 산정 방식은 **AHP 기반 다기준 의사결정 가중합 방식**이다.

기존처럼 항목별 가중치를 임의로 정하면 발표에서 다음 질문을 받을 가능성이 높다.

```text
왜 범죄위험은 35%인가?
왜 아동보호는 20%인가?
가로등과 경찰서 중 무엇이 더 중요한가?
이 점수가 실제로 신뢰할 수 있는가?
```

따라서 단순히 점수 공식을 제시하는 것이 아니라, **가중치를 정하는 절차 자체에 신뢰성을 부여하는 방식**이 필요하다.

AHP(Analytic Hierarchy Process, 계층분석법)는 여러 평가 기준을 쌍대비교하여 중요도를 산정하는 대표적인 다기준 의사결정 방법이다. 본 프로젝트에서는 안전점수 항목을 계층화하고, 각 항목 간 중요도를 비교하여 가중치를 산정하는 방식으로 사용한다.

## 최종 산정 구조

안전점수는 다음 항목을 0~100점으로 정규화한 뒤, AHP로 산정한 가중치를 적용해 계산한다.

```text
안전점수 =
w1 × 범죄위험 역점수
+ w2 × 야간보행 보조 점수
+ w3 × 아동보호 점수
+ w4 × 안전시설 접근성 점수
```

여기서 `w1, w2, w3, w4`는 임의로 정한 값이 아니라 AHP 쌍대비교를 통해 산정한 가중치다.

예시 항목:

```text
범죄위험 역점수:
생활안전지도 범죄주의구간 색상 등급을 안전점수로 변환한 값

야간보행 보조 점수:
가로등, 보안등 등 야간 시야 확보 시설과의 접근성

아동보호 점수:
아동안전지킴이집 접근성, 아동 범죄주의구간 여부

안전시설 접근성 점수:
경찰서, 소방서, 편의점 등 도움 요청 가능 시설과의 접근성
```

## 항목별 점수 정규화 방식

각 항목은 서로 단위가 다르기 때문에 그대로 더하지 않고 0~100점으로 변환한다.

### 1. 거리 기반 접근성 점수

시설물과 도로 사이의 거리를 기준으로 점수를 계산한다.

```text
접근성 점수 = max(0, 100 × (1 - 거리 / 기준거리))
```

예시 기준거리:

```text
가로등/보안등: 50m
편의점: 150m
아동안전지킴이집: 300m
경찰서/소방서: 500m
```

가까운 시설일수록 점수가 높고, 기준거리보다 멀면 0점에 가까워진다.

### 2. 범죄위험 역점수

생활안전지도 WMS의 범죄주의구간 색상 등급을 안전점수로 변환한다.

```text
위험 없음 = 100점
노랑 = 70점
주황 = 40점
빨강 = 10점
```

범죄위험이 높을수록 안전점수는 낮아져야 하므로, 위험도를 그대로 쓰지 않고 역점수로 변환한다.

### 3. 아동보호 점수

아동 보행 안전이라는 서비스 목적을 반영하기 위해 별도 항목으로 계산한다.

```text
아동안전지킴이집이 가까울수록 높은 점수
아동 범죄주의구간에 가까울수록 낮은 점수
아동보호시설 접근성이 좋을수록 높은 점수
```

### 4. 야간보행 보조 점수

밤길 보행에 직접 영향을 주는 조명 인프라를 반영한다.

```text
가로등, 보안등과 가까울수록 높은 점수
조명 시설이 부족한 도로일수록 낮은 점수
```

## AHP를 적용하는 이유

AHP를 쓰는 이유는 가중치의 임의성을 줄이기 위해서다.

단순 가중합 방식에서는 다음과 같은 문제가 생긴다.

```text
범죄위험 35%, 아동보호 20% 같은 비율의 근거가 약하다.
평가자가 보기에는 임의로 정한 값처럼 보일 수 있다.
발표 질의응답에서 가중치 근거를 설명하기 어렵다.
```

AHP를 적용하면 다음과 같이 설명할 수 있다.

```text
가중치는 임의로 부여하지 않았다.
항목 간 중요도를 쌍대비교하여 산정했다.
일관성 비율(CR)을 통해 판단의 논리적 일관성을 확인했다.
```

예시 쌍대비교 질문:

```text
범죄위험은 야간조명보다 얼마나 중요한가?
범죄주의구간 회피는 안전시설 접근성보다 얼마나 중요한가?
아동보호시설은 일반 편의시설보다 얼마나 중요한가?
야간조명은 편의점 접근성보다 얼마나 중요한가?
```

일관성 비율:

```text
CR < 0.1이면 쌍대비교 판단이 비교적 일관적이라고 본다.
```

## 발표용 최종 설명

```text
본 시스템은 안전점수를 임의 가중치로 산정하지 않고, AHP 기반 다기준 의사결정 방식을 적용했습니다.
먼저 범죄위험, 야간보행 보조, 아동보호, 안전시설 접근성 항목을 0~100점으로 정규화했습니다.
이후 항목 간 중요도를 쌍대비교하여 가중치를 산정하고, 일관성 비율을 통해 가중치 판단의 논리적 타당성을 검토했습니다.
따라서 본 점수는 절대적인 안전 보장이 아니라, 공공데이터 기반의 도로별 상대 안전도 지표로 활용됩니다.
```

## 예상 질문과 답변

### Q1. 가중치를 왜 그렇게 정했나요?

```text
가중치는 임의로 정하지 않고 AHP 쌍대비교를 통해 산정했습니다.
범죄위험, 야간조명, 아동보호, 안전시설 접근성 항목을 서로 비교하고, 그 결과를 바탕으로 항목별 중요도를 도출했습니다.
또한 일관성 비율을 확인하여 비교 판단이 논리적으로 일관적인지 검토했습니다.
```

### Q2. 이 점수가 실제 안전을 보장하나요?

```text
본 점수는 절대적인 안전 보장 지표가 아니라, 공공데이터 기반의 상대 안전도 지표입니다.
도로 간 안전 수준을 비교하고 위험구간을 회피하는 데 활용하는 목적입니다.
향후 실제 신고·사고 데이터와 비교하여 점수 체계를 보정할 계획입니다.
```

### Q3. 범죄위험 데이터가 가장 중요한 이유는 무엇인가요?

```text
본 서비스의 목적은 야간 보행 중 위험구간을 회피하는 것입니다.
따라서 범죄주의구간은 경로 선택에 직접적인 영향을 주는 핵심 요소로 보았습니다.
다만 범죄위험만 반영하면 조명, 아동보호시설, 도움 요청 가능 시설의 효과가 누락되므로, 여러 요소를 함께 고려하는 다기준 방식을 사용했습니다.
```

## 향후 신뢰성 보강 계획

현재 모델은 공공데이터 기반 초기 안전도 산정 모델이다. 향후에는 다음 방식으로 신뢰성을 보강할 수 있다.

```text
1. 실제 신고·사고 데이터와 안전점수의 상관성 분석
2. 엔트로피 가중치 방식과 AHP 가중치 비교
3. 사용자 피드백을 기반으로 위험구간 회피 결과 검증
4. 지역별 특성에 따른 기준거리 및 가중치 보정
```

## 비교 검토한 다른 방식

아래 방식들은 검토 대상이지만, 현재 프로젝트의 발표 및 구현 현실성을 고려하면 AHP 기반 가중합 방식이 가장 적합하다.

## 방식 1. 거리 기반 정규화 방식

시설물별로 임의 점수를 직접 부여하지 않고, 도로와 시설물 사이의 거리를 0~100점으로 변환하는 방식이다.

```text
시설 접근성 점수 = max(0, 100 × (1 - 거리 / 기준거리))
```

예시 기준거리:

```text
가로등: 50m
보안등: 50m
편의점: 150m
아동안전지킴이집: 300m
경찰서/지구대: 500m
소방서: 500m
```

장점:

```text
거리라는 객관적 기준을 사용한다.
시설물이 가까울수록 안전성이 높다는 설명이 쉽다.
기존 시설물 가중치보다 임의성이 줄어든다.
```

단점:

```text
기준거리 자체는 프로젝트에서 정해야 한다.
시설물의 중요도 차이를 따로 반영하려면 추가 가중치가 필요하다.
```

발표용 설명:

```text
시설물별 임의 점수 대신, 도로와 시설물 간 거리를 기반으로 접근성 점수를 산정했습니다.
```

## 방식 2. 등급 기반 점수 방식

거리나 위험도를 세부 수치로 바로 계산하지 않고, 일정 구간별 등급으로 나누어 점수화하는 방식이다.

시설 접근성 예시:

```text
50m 이내 = 100점
50~100m = 60점
100m 이상 = 20점
시설 없음 = 0점
```

범죄주의구간 예시:

```text
위험 없음 = 100점
노랑 = 70점
주황 = 40점
빨강 = 10점
```

장점:

```text
설명이 쉽다.
데이터가 조금 부정확해도 점수가 과도하게 흔들리지 않는다.
발표 자료로 표현하기 좋다.
```

단점:

```text
세밀한 거리 차이는 반영이 약하다.
등급 구간을 어떻게 나눴는지 설명이 필요하다.
```

발표용 설명:

```text
거리와 위험도를 등급으로 나누어 과도한 점수 편차를 줄이고, 해석 가능한 안전 등급으로 변환했습니다.
```

## 방식 3. 항목별 정규화 후 가중합 방식

모든 요소를 0~100점으로 정규화한 뒤, 항목별 중요도에 따라 가중합하는 방식이다.

예시 공식:

```text
최종 안전점수 =
w1 × 시설 접근성 점수
+ w2 × 범죄위험 역점수
+ w3 × 아동보호 점수
+ w4 × 야간보행 보조 점수
```

단, 이 방식만 사용할 경우 `w1~w4`를 어떻게 정했는지에 대한 근거가 필요하다.

항목 예시:

```text
시설 접근성 점수:
경찰서, 소방서, 편의점 등 시설물 접근성

범죄위험 역점수:
생활안전지도 범죄주의구간 색상 등급

아동보호 점수:
아동안전지킴이집 접근성, 아동 범죄주의구간

야간보행 보조 점수:
가로등, 보안등 접근성
```

장점:

```text
서로 단위가 다른 데이터를 비교 가능하게 만든다.
공식이 명확해서 발표 설명이 쉽다.
아동 보행 플랫폼이라는 목적을 별도 항목으로 반영할 수 있다.
```

단점:

```text
항목 가중치의 근거를 설명해야 한다.
구현이 방식 1, 2보다 조금 더 복잡하다.
```

발표용 설명:

```text
서로 단위가 다른 데이터를 직접 더하지 않고, 모든 요소를 0~100점으로 정규화한 뒤 항목별 중요도에 따라 가중합했습니다.
```

## 방식 4. 위험 감점 중심 방식

모든 도로를 기본적으로 안전하다고 보고, 범죄주의구간 등 위험 요소가 있는 경우 감점하는 방식이다.

예시 공식:

```text
기본점수 = 100

최종 안전점수 =
100
- 일반 범죄위험 감점
- 아동 범죄위험 감점
+ 시설물 보정점수
```

감점 예시:

```text
일반 범죄주의구간
노랑 = -10
주황 = -25
빨강 = -45

아동 범죄주의구간
노랑 = -10
주황 = -20
빨강 = -35
```

시설 보정 예시:

```text
조명 근처 = +5
아동안전지킴이집 근처 = +10
경찰서/지구대 근처 = +15
```

장점:

```text
위험구간 회피 목적이 명확하다.
범죄주의구간 데이터의 역할을 설명하기 쉽다.
안전 길안내와 직접적으로 연결된다.
```

단점:

```text
시설물 데이터의 영향이 상대적으로 작아진다.
감점 폭을 어떻게 정했는지 설명이 필요하다.
```

발표용 설명:

```text
안전점수는 가산보다 위험 감점을 중심으로 설계하여, 위험구간 회피가 경로 선택에 우선 반영되도록 했습니다.
```

## 방식 5. 순위 기반 상대평가 방식

절대 점수 대신 전체 도로의 점수 분포를 기준으로 상대 등급을 부여하는 방식이다.

예시:

```text
상위 20% = 안전
중간 60% = 보통
하위 20% = 위험
```

또는:

```text
상위 25% = 초록
중간 50% = 노랑
하위 25% = 빨강
```

장점:

```text
절대 점수 기준의 임의성을 줄일 수 있다.
지역 내 상대적으로 안전한 도로와 위험한 도로를 구분하기 쉽다.
데이터 분포에 맞게 자동 조정된다.
```

단점:

```text
절대적으로 안전한지 설명하기는 어렵다.
지역이 바뀌면 기준도 함께 바뀐다.
```

발표용 설명:

```text
절대 점수의 임의성을 줄이기 위해 전체 도로의 점수 분포를 기준으로 상대 안전 등급을 산정했습니다.
```

## 방식 6. AHP 기반 가중치 산정 방식

AHP는 여러 평가 요소를 쌍대비교하여 가중치를 산정하는 의사결정 기법이다. 시설물이나 위험 요소의 중요도를 팀원 또는 전문가 평가로 비교해 가중치를 도출한다.

예시 비교 항목:

```text
범죄위험은 조명보다 얼마나 중요한가?
아동보호시설은 편의점보다 얼마나 중요한가?
경찰서는 소방서보다 얼마나 중요한가?
```

장점:

```text
가중치가 단순 임의값이 아니라 의사결정 절차를 통해 정해진다.
연구형 발표에서 신뢰성 있게 보일 수 있다.
```

단점:

```text
쌍대비교 설문이나 평가 과정이 필요하다.
지금 당장 구현하기에는 번거롭다.
```

발표용 설명:

```text
향후에는 AHP 기법을 적용하여 시설물별 중요도를 정량적으로 산정하고, 가중치의 임의성을 줄일 수 있습니다.
```

## 방식 7. 실제 사건 데이터 검증 방식

실제 신고, 사고, 범죄 발생 데이터와 안전점수 결과를 비교하여 점수 체계를 검증하는 방식이다.

검증 예시:

```text
안전점수가 낮은 도로에서 실제 신고가 많은가?
안전점수가 높은 도로에서 실제 위험 사건이 적은가?
위험구간으로 분류된 도로가 실제 범죄주의구간과 겹치는가?
```

장점:

```text
가장 객관적인 검증 방식이다.
점수 체계의 신뢰성을 실제 데이터로 확인할 수 있다.
```

단점:

```text
실제 사건 데이터 확보가 어렵다.
개인정보나 공개 제한 문제가 있을 수 있다.
시간이 많이 걸린다.
```

발표용 설명:

```text
본 프로젝트에서는 공공데이터 기반 초기 모델을 구축하고, 향후 실제 신고·사고 데이터와 비교하여 점수 체계를 보정할 계획입니다.
```

## 최종 추천안

현재 프로젝트에는 다음 조합이 가장 적합하다.

```text
방식 1. 거리 기반 정규화
+ 방식 2. 위험등급 점수화
+ 방식 3. 항목별 정규화 후 가중합
+ 방식 6. AHP 기반 가중치 산정
+ 방식 7. 실제 사건 데이터 기반 사후 검증 계획
```

최종 공식:

```text
안전점수 =
w1 × 범죄위험 역점수
+ w2 × 야간보행 보조 점수
+ w3 × 아동보호 점수
+ w4 × 안전시설 접근성 점수
```

여기서 `w1, w2, w3, w4`는 고정 임의값이 아니라 AHP 쌍대비교를 통해 산정한 가중치다.

이 방식을 추천하는 이유:

```text
시설물 개별 점수를 임의로 직접 부여하지 않는다.
거리 기반 접근성을 사용하므로 객관적인 설명이 가능하다.
범죄위험은 생활안전지도 WMS의 색상 등급을 반영할 수 있다.
아동 보행 플랫폼이라는 목적을 별도 항목으로 반영할 수 있다.
모든 요소가 0~100점으로 정규화되어 비교 가능하다.
가중치는 AHP 절차로 산정하므로 임의 가중치라는 비판을 줄일 수 있다.
일관성 비율(CR)을 통해 쌍대비교 판단의 논리적 일관성을 확인할 수 있다.
```

최종 발표용 문장:

```text
본 시스템은 안전점수를 임의 가중치로 산정하지 않고, AHP 기반 다기준 의사결정 방식을 적용했습니다.
먼저 범죄위험, 야간보행 보조, 아동보호, 안전시설 접근성 항목을 0~100점으로 정규화했습니다.
이후 항목 간 중요도를 쌍대비교하여 가중치를 산정하고, 일관성 비율을 통해 가중치 판단의 논리적 타당성을 검토했습니다.
따라서 본 점수는 절대적인 안전 보장이 아니라, 공공데이터 기반의 도로별 상대 안전도 지표로 활용됩니다.
```

주의할 표현:

```text
정답 점수
절대 안전도
완전히 검증된 안전성
안전을 보장하는 점수
```

권장 표현:

```text
공공데이터 기반 상대 안전도 지표
도로별 안전 수준 비교 지표
위험구간 회피를 위한 보행 안전 점수
AHP 기반 다기준 안전도 산정 모델
```
